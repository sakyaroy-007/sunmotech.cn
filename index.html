开发中 · In development

MacCash （名称暂定）

面向 iOS 与跨平台开发团队的 macOS 构建算力服务。macOS build capacity for iOS and cross-platform teams.

把 GitHub Actions 的 macOS 构建任务放到物理 Mac 上运行，按分钟计费。接入从修改 workflow 里的 runs-on 开始。

  • 物理 Mac，不使用虚拟机
  • GitHub Actions self-hosted runner 方式接入
  • 按构建用时计费，以分钟为单位
# .github/workflows/build.yml
jobs:
  build:
-   runs-on: macos-latest
+   runs-on: [self-hosted, maccash-standard]
    steps:
      - uses: actions/checkout@v4
      - run: xcodebuild -scheme App build
