SAKYAROY LABS 是 Sunmo 的专业音频插件系列。首款作品 Silencio 已经定版，下一件作品正在幕布之后成形。

认识 Silencio 即将揭幕

Lab / 001 · Silencio · 人声降噪

让声音， 回到主角。

削减人声背后的噪声，让注意力回到表达本身。在直觉的控制与清晰的反馈之间，找到你的声音。

1.1.0 已定版AU / VST3Apple 芯片原生

Designed for listening

少一点干扰，多一点表达。

  • 01

    不用先录一段噪声

    直接播放音频，Silencio 就会持续自动估计噪声，无需先录制噪声片段来「学习」。

  • 02

    三个旋钮，频谱看得见

    通过 Attenuation、Focus 与 Bias 调整处理；频谱显示帮助观察保留与移除的能量。

  • 03

    听见每一次取舍

    Noise listen 用来检查被移除的成分，配合旁通（Bypass）对比，让判断回到双耳。

Hands on · 转一转

拖动旋钮，看它怎么取舍。

上下拖动或用方向键调节，双击回到初始值。建议从 Attenuation −10 dB、Focus 50、Bias 0 dB 开始。
