macYourCash · macOS 构建算力 · 开发中

你的 Mac， 比你想象的更值钱。

macYourCash 把中国大陆机主闲置的 Mac 组织成构建算力池：开发团队的 GitHub Actions macOS 任务跑在物理 Mac 上，按分钟计费；机主在 Mac 空闲时接单。

The pool · 算力池

空闲时接单，主人回来就让路。

任务从 GitHub Actions 排队派到空闲的 Mac 上。机主开始用电脑，这台 Mac 就不再接新任务，正在跑的任务照常收尾。

空闲，可接单 正在构建 机主在用，不接新单 示意动画，不是实时数据

For teams · 开发团队

改一行 runs-on，构建就上物理 Mac。

workflow 照常由 GitHub 编排，macYourCash 把机器注册成 GitHub Actions 的 self-hosted runner。接入通常从修改 runs-on 开始，再按我们的工具链检查依赖、签名和缓存配置。

.github/workflows/build.yml
name: build
on: [push]
jobs:
  build:
-   runs-on: macos-latest+   runs-on: [self-hosted, 档位]    steps:
      - uses: actions/checkout@v4
      - run: xcodebuild -scheme App build
1

安装 GitHub App

通过 GitHub 的标准安装流程装到你的账号或组织上，自己选它能访问哪些仓库。

2

选一个私有仓库

macYourCash 只服务私有仓库。公开仓库可以直接用 GitHub 自带的免费 macOS runner。

3

改一行 runs-on

换成 self-hosted 加档位标签，需要完整 Xcode 时再加上对应的大版本标签。

Tiers · 档位

按芯片分档，按分钟计费。

四个档位按 Apple 芯片家族划分。构建按用时计费，不足一分钟按一分钟算。

{{INFO}}基础环境是 macOS 加 Apple 命令行工具，不是 GitHub macOS 镜像的完整拷贝。完整 Xcode 只在部分机器上有，可以按大版本选机；Homebrew、CocoaPods 不预装；任务以无 sudo 的受限用户运行，没有 Docker、虚拟机和图形会话。

For owners · 机主

Mac 闲着的时候，让它接单。

装一个菜单栏小工具，选好接单方式就行。你回来用电脑，它会自己让路。

Manual

手动

你点「开始出租」才接单，什么时候出租完全由你决定。

Auto

自动

Mac 空闲就接单，可以设定接单的时间段。

Shared

共享

你在用也能接，但只接比这台 Mac 低一档的任务，并降到后台优先级运行。标准档及以上机型可用。

  • 01

    你回来，它就让路

    检测到你在持续使用电脑，就不再接新任务；正在跑的任务照常收尾。

  • 02

    碰一下鼠标不算

    按一段时间里的持续操作来判断你是不是回来了，手滑碰一下不会让机器下线。

  • 03

    进池门槛

    M 系列芯片，内存 16 GB 起。机主目前只接受中国大陆用户。

The fine print · 说在前面

把边界讲清楚。

构建跑在别人的物理 Mac 上，有些事我们现在做不到，先说清楚。

  • —

    不承诺机主看不到你的代码

    机主是那台 Mac 的管理员。我们会处理可验证的异常和举报，但不承诺能即时发现、删除或阻止泄露。

  • —

    不承诺随时有机器

    机器来自空闲时出租的机主；没有合适的机器在线时，任务会排队。

  • —

    签名材料不要放到构建机上

    签名证书、钥匙串密码、App Store Connect 密钥这类长期密钥，请在你自己控制的机器或签名服务上处理。

  • —

    暂不公布 SLA 数字

    服务等级协议还在起草，现在不给可用率、提速比例这类数字。
